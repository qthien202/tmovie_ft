# Changelog

Release notes shown to users come straight from the section that matches the
release tag (the `## vX.Y.Z` heading). The in-app update dialog renders this as
plain text, so keep it readable without Markdown styling: short lines, emoji
section markers, and "•" bullets.

## v1.1.0

✨ What's new
• Brand-new cinematic look — Home and movie Detail now open with full-screen, edge-to-edge hero artwork in an immersive streaming style.
• Redesigned Play button — a clean white circular Play control sits right next to each title; tap anywhere on the hero to start watching.
• Refreshed Search — a content-led Discover screen that surfaces titles before you even start typing.
• Refreshed Profile — a new immersive teal-washed header.

🛠 Improvements
• Category tabs no longer hide behind the phone's notch.
• On Android, the bottom navigation bar now clears the system gesture bar (iOS layout unchanged).

⚡ Performance & stability
• Posters and backdrops now load at the right resolution — far less memory used, fixing occasional out-of-memory crashes on Android.
• Added app-wide crash protection so a network or startup hiccup no longer leaves the app stuck on a blank screen.
